====================================================================
บริษัทสมมติในระบบทดลอง: บริษัท ตัวอย่าง อินดัสทรี จำกัด (Demo Co., Ltd.)

ระบบนี้คืออะไร
--------------
ระบบบริหารพาเลทของโรงงาน แยกประเภท RM (วัตถุดิบ) / PK (บรรจุภัณฑ์) / FG (สินค้าสำเร็จรูป) / พาเลทพลาสติก
- แดชบอร์ด: KPI พาเลททั้งหมด พร้อมใช้ เบิกไปใช้งาน ชำรุด กำลังซ่อม ตัดจำหน่าย, กราฟย้อนหลัง 7/14/30 วัน
- รับเข้า · เบิกจ่าย (เลือกฝ่าย) · รับคืน (สภาพดี / ชำรุด) · แจ้งชำรุด
- งานซ่อม: ชำรุด → กำลังซ่อม → ซ่อมเสร็จ / ตัดจำหน่าย (ทำบางส่วนได้ — แยกใบอัตโนมัติ)
- คงเหลือ, ประวัติเคลื่อนไหว (ค้นหา / ส่งออก Excel), บันทึกประวัติ (Log), ตั้งค่าฝ่าย
- หน้าเว็บ: GitHub Pages (โฟลเดอร์ docs/) · หลังบ้าน: Google Apps Script + Google Sheets (สคริปต์สร้างเอง)

ข้อแตกต่างของฉบับทดลอง
------------------------
- มีแถบ "🧪 ระบบทดลองใช้ (Demo)" ด้านบนทุกหน้า แสดงวัน-เวลารีเซ็ตครั้งถัดไป + นับถอยหลัง (ชม. / นาที)
  และข้อความติดต่อ (แก้ได้ที่ docs/config.js → DEMO_CONTACT)
- ทดลองใช้ได้คนละ 5 ชั่วโมง (นับตาม IP + อุปกรณ์): มีป้ายนับเวลาที่มุมซ้ายล่าง เมื่อครบ 5 ชั่วโมงจะขึ้นหน้าจอ
  "หมดเวลาทดลอง" พร้อมราคาและช่องทางติดต่อ (สคริปต์กลาง docs/assets/trial-gate.js — คัดลอกมาจาก TrialGate ห้ามแก้)
  ตั้งค่าที่ docs/config.js → DEMO_TRIAL (gateUrl / app: 'pallet' / hours: 5 / contact / priceHtml)
  ถ้ายังไม่ใส่ gateUrl หรือเชื่อมต่อ Trial Gate ไม่ได้ เว็บยังใช้งานได้ตามปกติ (ไม่ล็อก)
- ข้อมูลตัวอย่าง (พาเลทในระบบ ~520 ตัว จาก 64 รายการเคลื่อนไหวย้อนหลัง ~4 สัปดาห์, ใบแจ้งซ่อม 10 ใบทุกสถานะ,
  พาเลทถูกเบิกไปอยู่กับทั้ง 8 ฝ่าย) — วันที่อิงจากวันที่รีเซ็ต จึงดูเป็นปัจจุบันเสมอ
- ข้อมูลส่วนกลางรีเซ็ตกลับเป็นข้อมูลตัวอย่างอัตโนมัติทุก 5 ชั่วโมง (trigger ทุก 1 ชั่วโมง ตรวจว่าครบ 5 ชม.
  นับจาก DEMO_LAST_RESET หรือยัง — จึงรีเซ็ตจริงภายใน 5–6 ชม.) · แถบด้านบนแสดง "รีเซ็ตครั้งถัดไป" = รีเซ็ตล่าสุด + 5 ชม.
- ปุ่ม "รีเซ็ตข้อมูล / Reset data" บนแดชบอร์ดแสดงอยู่แต่ล็อก 🔒 (มีในเวอร์ชันเต็ม)
- ปิดการแจ้งเตือน Microsoft Teams (บันทึกเป็น log "[DEMO] ... skipped" เท่านั้น) ไม่มีการส่งอีเมลใด ๆ
- ใส่รหัสผิดเกิน 10 ครั้ง ล็อกเพียง 1 นาที (ฉบับจริง 15 นาที) เพื่อไม่ให้ผู้ทดลองคนอื่นถูกล็อกนาน
- คีย์ที่เก็บในเบราว์เซอร์ขึ้นต้นด้วย demo_pallet_ (ไม่ชนกับเว็บจริงบนโดเมน github.io เดียวกัน)

บัญชีทดลอง (แสดงในหน้าต่าง "ผู้ใช้งาน" และหน้าต่างใส่รหัสของเว็บด้วย)
------------------------------------------------------------------------
ระบบนี้ไม่มีหน้าเข้าสู่ระบบ (เหมือนฉบับจริง):
- ชื่อผู้ใช้งาน: กดมุมขวาบน แล้วพิมพ์ชื่อใดก็ได้ เช่น ผู้ทดลองระบบ (ใช้บันทึกเป็น "ผู้ทำรายการ")
- รหัสผู้ดูแล: demo1234
  ใช้สำหรับ ดูบันทึกประวัติ (Log) — (แก้ไข/ลบรายการ · ตั้งค่าฝ่าย · รีเซ็ตข้อมูล ล็อกไว้ในฉบับทดลอง)

ฉบับทดลองแบบย่อ — ใช้ได้ / ล็อก 🔒
-----------------------------------
ฉบับทดลองให้ลองใช้และเห็นภาพรวมเท่านั้น ไม่ใช่ทั้งระบบ
ใช้งานได้:
- แดชบอร์ด (KPI, กราฟ 7/14/30 วัน, เส้นทางพาเลท, งานซ่อมสรุป, รายการล่าสุด)
- คงเหลือ (การ์ด + ตาราง + พาเลทที่อยู่กับแต่ละฝ่าย)
- ประวัติเคลื่อนไหว: ดู / ค้นหา / กรองตามวันที่ ประเภท รายการ ฝ่าย
- งานซ่อม: ดูบอร์ดสถานะ (ชำรุด → กำลังซ่อม → เสร็จ) อย่างเดียว
- บันทึกประวัติ (Log): ดู / ค้นหา / กรองหมวด (ใส่รหัส demo1234)
- ทำรายการ: รับเข้า · เบิกจ่าย · รับคืน (สภาพดี)
- ตั้งชื่อผู้ใช้งาน (มุมขวาบน)
ล็อก 🔒 (ปุ่ม/เมนูยังแสดง แต่กดแล้วขึ้น "🔒 ฟีเจอร์นี้มีในเวอร์ชันเต็ม — <DEMO_CONTACT>"
และเซิร์ฟเวอร์ปฏิเสธ action เหล่านี้ด้วย {ok:false, error:'ฟีเจอร์นี้มีในเวอร์ชันเต็ม', code:'DEMO_LOCKED'}):
- แจ้งชำรุด (เมนู + ปุ่มในหน้างานซ่อม)                     → damage
- รับคืนสภาพชำรุด (เปิดใบแจ้งซ่อม)                          → return ที่ condition = damaged
- งานซ่อม: ส่งซ่อม / ซ่อมเสร็จ / ซ่อมไม่ได้ (ตัดจำหน่าย)      → repair_start, repair_done, scrap
- แก้ไข / ลบรายการย้อนหลัง และใบแจ้งซ่อม                    → movement_update, movement_delete, repair_update, repair_delete
- ตั้งค่าฝ่าย (เมนู)                                        → dept_save, dept_delete
- ปุ่มรีเซ็ตข้อมูล / Reset data                             → reset_data
- ส่งออก Excel ของประวัติเคลื่อนไหว และของ Log              → export, logs_export
- การแจ้งเตือน Microsoft Teams: ปิดอยู่แล้วในฉบับทดลอง (ไม่มีหน้าตั้งค่า ไม่ส่งข้อความใด ๆ)
รายการ action ที่ล็อกอยู่ที่ DEMO_LOCKED_ACTIONS ใน apps-script/Demo.gs

ขั้นตอนติดตั้ง (เจ้าของระบบทำครั้งเดียว)
------------------------------------------
1) ไปที่ https://script.google.com → New project (โปรเจกต์ Apps Script แบบ standalone ใหม่)
   ตั้งชื่อเช่น "Pallet Hub Demo API"
2) วางไฟล์โค้ด:
   - apps-script/Code.gs → วางแทนเนื้อหาไฟล์ Code.gs ที่มีอยู่
   - กด + เพิ่มไฟล์ Script ชื่อ Demo แล้ววางเนื้อหา apps-script/Demo.gs (ต้องมีทั้ง 2 ไฟล์)
   - Project Settings → ติ๊ก "Show appsscript.json" แล้ววางเนื้อหา appsscript.json (timeZone Asia/Bangkok)
   - กด Save
3) เลือกฟังก์ชัน setupDemo แล้วกด Run หนึ่งครั้ง → อนุญาตสิทธิ์ (Google Sheets + Triggers)
   ระบบจะ: สร้างสเปรดชีต "Pallet Hub Demo Database", ตั้งรหัส demo1234, ใส่ข้อมูลตัวอย่าง,
   บันทึก DEMO_LAST_RESET และสร้าง trigger ทุก 1 ชั่วโมง demoAutoReset (มีเพียง 1 ตัวเสมอ แม้รันซ้ำ —
   trigger เดิมแบบรายวันของรุ่นก่อนจะถูกลบแทนที่ให้อัตโนมัติ)
   *** ถ้าเคยติดตั้งรุ่นก่อน (รีเซ็ตทุก 3 วัน) แล้ว: วาง Code.gs + Demo.gs ใหม่ → รัน setupDemo อีกครั้ง →
       Deploy → Manage deployments → Edit → Version: New version → Deploy (URL /exec เดิม)
4) Deploy → New deployment → ประเภท Web app
   - Execute as: Me
   - Who has access: Anyone
   กด Deploy แล้วคัดลอก URL ที่ลงท้ายด้วย /exec
5) เปิด docs/config.js แล้วแทนที่ PASTE_DEPLOYED_EXEC_URL_HERE ด้วย URL /exec
   (และแก้ DEMO_CONTACT เป็นช่องทางติดต่อจริง เช่น ลิงก์ Fastwork / LINE ID)
   และแทนที่ PASTE_TRIAL_GATE_URL_HERE (ใน DEMO_TRIAL) ด้วย URL /exec ของโปรเจกต์ Apps Script "Trial Gate"
   (โปรเจกต์แยกต่างหาก ใช้ร่วมกันทุกเว็บเดโม — โค้ดอยู่ที่โฟลเดอร์ TrialGate/apps-script/Code.gs ไม่ต้องวางในโปรเจกต์นี้)
6) สร้าง GitHub repository ใหม่ → push โฟลเดอร์นี้ขึ้นไป (git remote add origin ... ; git push -u origin main)
7) GitHub repo → Settings → Pages → Source: Deploy from a branch → Branch: main / folder: /docs → Save
   รอ 1–2 นาที แล้วเปิด https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/

ฟังก์ชันใน Apps Script (Demo.gs)
---------------------------------
- setupDemo()      รันครั้งเดียวตอนติดตั้ง (รันซ้ำได้ ไม่สร้างสเปรดชีต/trigger ซ้ำ — แต่จะรีเซ็ตข้อมูล)
- demoAutoReset()  trigger เรียกทุก 1 ชั่วโมง: ถ้าครบ 5 ชั่วโมง (DEMO_RESET_HOURS) นับจาก DEMO_LAST_RESET จะรีเซ็ตข้อมูล
- resetDemoNow()   รีเซ็ตกลับเป็นข้อมูลตัวอย่างทันที (กดรันเองได้ทุกเมื่อ)
- seedDemoData_()  ล้างทุกชีตแล้วเขียนข้อมูลตัวอย่าง (ข้อมูลตัวอย่างคือรายการ DEMO_SEED_PLAN ใน Demo.gs)
- API: GET ?action=demo_info และใน ?action=bootstrap (ฟิลด์ demo) → lastReset / nextReset (= lastReset + 5 ชม.) / intervalHours
