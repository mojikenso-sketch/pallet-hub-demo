ระบบนี้คืออะไร
--------------
ระบบบริหารพาเลทของโรงงาน แยกประเภท RM (วัตถุดิบ) / PK (บรรจุภัณฑ์) / FG (สินค้าสำเร็จรูป) / พาเลทพลาสติก
- แดชบอร์ด: KPI พาเลททั้งหมด พร้อมใช้ เบิกไปใช้งาน ชำรุด กำลังซ่อม ตัดจำหน่าย, กราฟย้อนหลัง 7/14/30 วัน
- รับเข้า · เบิกจ่าย (เลือกฝ่าย) · รับคืน (สภาพดี / ชำรุด) · แจ้งชำรุด
- งานซ่อม: ชำรุด → กำลังซ่อม → ซ่อมเสร็จ / ตัดจำหน่าย (ทำบางส่วนได้ — แยกใบอัตโนมัติ)
- คงเหลือ, ประวัติเคลื่อนไหว (ค้นหา / ส่งออก Excel), บันทึกประวัติ (Log), ตั้งค่าฝ่าย
- หน้าเว็บ: GitHub Pages (โฟลเดอร์ docs/) · หลังบ้าน: Google Apps Script + Google Sheets (สคริปต์สร้างเอง)

ข้อแตกต่างของฉบับทดลอง
------------------------
- มีแถบ "🧪 ระบบทดลองใช้ (Demo)" ด้านบนทุกหน้า แสดงวัน-เวลารีเซ็ตครั้งถัดไป + นับถอยหลัง
  และข้อความติดต่อ (แก้ได้ที่ docs/config.js → DEMO_CONTACT)
- ข้อมูลตัวอย่าง (พาเลทในระบบ ~520 ตัว จาก 64 รายการเคลื่อนไหวย้อนหลัง ~4 สัปดาห์, ใบแจ้งซ่อม 10 ใบทุกสถานะ,
  พาเลทถูกเบิกไปอยู่กับทั้ง 8 ฝ่าย) — วันที่อิงจากวันที่รีเซ็ต จึงดูเป็นปัจจุบันเสมอ
- รีเซ็ตกลับเป็นข้อมูลตัวอย่างอัตโนมัติทุก 3 วัน (trigger รายวันเวลา ~07:00 น.)
- ปุ่ม "รีเซ็ตข้อมูล / Reset data" บนแดชบอร์ด = กลับเป็นข้อมูลตัวอย่างเริ่มต้น (ไม่ใช่ล้างว่าง)
- ปิดการแจ้งเตือน Microsoft Teams (บันทึกเป็น log "[DEMO] ... skipped" เท่านั้น) ไม่มีการส่งอีเมลใด ๆ
- ใส่รหัสผิดเกิน 10 ครั้ง ล็อกเพียง 1 นาที (ฉบับจริง 15 นาที) เพื่อไม่ให้ผู้ทดลองคนอื่นถูกล็อกนาน
- คีย์ที่เก็บในเบราว์เซอร์ขึ้นต้นด้วย demo_pallet_ (ไม่ชนกับเว็บจริงบนโดเมน github.io เดียวกัน)

ระบบนี้ไม่มีหน้าเข้าสู่ระบบ (เหมือนฉบับจริง):
- ชื่อผู้ใช้งาน: กดมุมขวาบน แล้วพิมพ์ชื่อใดก็ได้ เช่น ผู้ทดลองระบบ (ใช้บันทึกเป็น "ผู้ทำรายการ")
- รหัสผู้ดูแล: demo1234
  ใช้สำหรับ แก้ไข/ลบรายการ · ดูบันทึกประวัติ (Log) · ตั้งค่าฝ่าย · รีเซ็ตข้อมูล

ขั้นตอนติดตั้ง (เจ้าของระบบทำครั้งเดียว)
------------------------------------------
1) ไปที่ https://script.google.com → New project (โปรเจกต์ Apps Script แบบ standalone ใหม่)
   ตั้งชื่อเช่น "Pallet Hub Demo API"
2) วางไฟล์โค้ด:
   - apps-script/Code.gs → วางแทนเนื้อหาไฟล์ Code.gs ที่มีอยู่
   - กด + เพิ่มไฟล์ Script ชื่อ Demo แล้ววางเนื้อหา apps-script/Demo.gs (ต้องมีทั้ง 2 ไฟล์)
   - Project Settings → ติ๊ก "Show appsscript.json" แล้ววางเนื้อหา appsscript.json (timeZone Asia/Bangkok)
   - กด Save
3) เลือกฟังก์ชัน setupDemo แล้วกด Run หนึ่งครั้ง → อนุญาตสิทธิ์ (Google Sheets + Triggers)
   ระบบจะ: สร้างสเปรดชีต "Pallet Hub Demo Database", ตั้งรหัส demo1234, ใส่ข้อมูลตัวอย่าง,
   บันทึก DEMO_LAST_RESET และสร้าง trigger รายวัน demoAutoReset (มีเพียง 1 ตัวเสมอ แม้รันซ้ำ)
4) Deploy → New deployment → ประเภท Web app
   - Execute as: Me
   - Who has access: Anyone
   กด Deploy แล้วคัดลอก URL ที่ลงท้ายด้วย /exec
5) เปิด docs/config.js แล้วแทนที่ PASTE_DEPLOYED_EXEC_URL_HERE ด้วย URL /exec
   (และแก้ DEMO_CONTACT เป็นช่องทางติดต่อจริง เช่น ลิงก์ Fastwork / LINE ID)
6) สร้าง GitHub repository ใหม่ → push โฟลเดอร์นี้ขึ้นไป (git remote add origin ... ; git push -u origin main)
7) GitHub repo → Settings → Pages → Source: Deploy from a branch → Branch: main / folder: /docs → Save
   รอ 1–2 นาที แล้วเปิด https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/

ฟังก์ชันใน Apps Script (Demo.gs)
---------------------------------
- setupDemo()      รันครั้งเดียวตอนติดตั้ง (รันซ้ำได้ ไม่สร้างสเปรดชีต/trigger ซ้ำ — แต่จะรีเซ็ตข้อมูล)
- demoAutoReset()  trigger เรียกทุกวัน: ถ้าครบ 3 วันนับจาก DEMO_LAST_RESET จะรีเซ็ตข้อมูล
- resetDemoNow()   รีเซ็ตกลับเป็นข้อมูลตัวอย่างทันที (กดรันเองได้ทุกเมื่อ)
- seedDemoData_()  ล้างทุกชีตแล้วเขียนข้อมูลตัวอย่าง (ข้อมูลตัวอย่างคือรายการ DEMO_SEED_PLAN ใน Demo.gs)
- API: GET ?action=demo_info และใน ?action=bootstrap (ฟิลด์ demo) → lastReset / nextReset
